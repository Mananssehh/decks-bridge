# Decks Bridge — Windows beta (send this folder)

Private testing build for **Windows 10/11 (64-bit)**.

## What's in this folder

| File | Use |
|------|-----|
| **Decks Bridge Setup.exe** | Recommended — installs to Program Files |
| **Decks Bridge Portable.exe** | No installer — run from anywhere |
| **Decks Bridge.zip** | Portable exe in a zip |
| **TEST_INSTALL.md** | Step-by-step install + SmartScreen help |

## Quick start (testers)

1. Run **Decks Bridge Setup.exe**
2. If SmartScreen warns: **More info → Run anyway**
3. Launch from the Start Menu
4. Pair with your Decks event using the 6-digit code

See **TEST_INSTALL.md** for full instructions.
