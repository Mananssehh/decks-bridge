# Decks Bridge — Mac beta (send this folder)

Private testing build for **Apple Silicon Macs** (M1/M2/M3/M4).

## What's in this folder

| File | Use |
|------|-----|
| **Decks Bridge.dmg** | Recommended — drag to Applications |
| **Decks Bridge.zip** | Alternative if DMG doesn't work |
| **TEST_INSTALL.md** | Step-by-step install + Gatekeeper help |

## Quick start (testers)

1. Open **Decks Bridge.dmg**
2. Drag **Decks Bridge** to Applications
3. If macOS blocks it: **System Settings → Privacy & Security → Open Anyway** (says "damaged"? see TEST_INSTALL.md)
4. Pair with your Decks event using the 6-digit code

See **TEST_INSTALL.md** for full instructions.
